## Frontend

### 1. Install NVM and Use Node 22.12.0

Follow this guide to install NVM:  
[Node Version Manager (NVM) Install Guide – freeCodeCamp](https://www.freecodecamp.org/news/node-version-manager-nvm-install-guide/)

### 2. Navigate to the Frontend Folder

```bash
cd frontend
```

### 3. Use the Correct Node Version

```bash
nvm use 22.12.0
```

### 4. Install Dependencies

```bash
npm install
```

### 5. Run the Development Server

```bash
npm run dev
```
